# Double-Slit Key Simulation

이 저장소는 이중슬릿 간섭무늬를 이용한 광학 키 전송 프로토콜의 최종 평가·검증 시뮬레이션을 담고 있습니다.

## 시뮬레이션 개요

- Alice가 1,000개의 광자를 한 블록씩 순차적으로 전송
- 10,000개 블록을 10초 동안 처리
- 이중슬릿 간격과 100m 전파 조건에서 1550nm·775nm 파장, 위상 0·π를 사용
- Bob은 1m 검출면을 100픽셀(1cm 간격)로 읽어 상태를 복호화
- Eve의 경로 측정, 검출 손실, 위상 흔들림, 배경 검출을 조절 가능
- Bob의 비트 오류율, Alice–Bob 키 일치 여부, 간섭무늬 편차, 도청 경보를 확인

`index.html`을 브라우저에서 열면 별도 설치 없이 실행할 수 있습니다.

## 주의

이 프로그램은 제안한 프로토콜의 이론적 동작과 통계적 경향을 검토하기 위한 시뮬레이션입니다. 실제 양자암호 보안성이나 실험 장치의 성능을 보증하지 않으며, 실제 구현에는 광원·검출기·광학 정렬·보정에 대한 별도 검증이 필요합니다.
